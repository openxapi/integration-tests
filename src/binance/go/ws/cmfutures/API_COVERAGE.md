## Supporting Helpers

- REST scaffolding (`github.com/openxapi/binance-go/rest/cmfutures`) fetches exchange info and ticker prices to
  produce valid limit orders and infer position side dual settings.
- Shared assertion utilities validate numeric/string fields and timestamp freshness.
- Log harness (`unhandledCatcher`) fails tests if the SDK emits "unhandled message" warnings.
